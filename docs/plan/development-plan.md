# agent-sims 迭代计划

> 创建日期: 2026-10-03
> **本文件是状态真相源:里程碑与完成状态只在此维护,不回填过程。**

## 里程碑

### M0: 立项与方案定稿

- 目标: 项目骨架、技术调研、需求基准、总体架构全部定稿
- 状态: **已完成**(2026-10-03)

### M1: 工程基座

- 目标: pnpm workspace 落地(apps/web、apps/server、packages/shared);docker 开发环境;DB 基座(schema 四域 + 首版迁移 + seed 骨架);shared Zod 协议包;server /health
- 验收标准: `docker compose -f docker/docker-compose.dev.yml up` 起 postgres;`pnpm dev` 后 migrate+seed 跑通;访问 /health 返回 ok
- 状态: 未开始

### M2: 世界模拟 MVP

- 目标: 1s 固定 tick/游戏时钟/昼夜节律/暂停恢复;小地图+场所;角色移动寻路;体力/幸福/金币数值衰减;Socket.IO 快照+增量;Phaser 渲染+插值;React HUD 外壳
- 验收标准: 浏览器看到角色按 tick 平滑移动;点击暂停世界立即冻结、恢复无状态丢失(requirement §11)
- 状态: 未开始

### M3: 核心玩法闭环

- 目标: 学习/工作/生活三类活动;打工赚币、消费、租房、买房、买家具;数值面板与反馈
- 验收标准: requirement §11「核心循环闭环」条通过
- 状态: 未开始

### M4: Agent 内核与托管

- 目标: 意图指令层(双来源原子切换);感知+记忆流(Jev 打分+pgvector 三因子检索);日计划/重规划;四层决策路由+token 记账;行动气泡;记忆/日程面板;人设访谈
- 验收标准: requirement §11 气泡可见/切换<1s/生活方针遵守/**高频动作零慢思考调用**各条通过
- 状态: 未开始

### M5: 睡眠与梦境记忆

- 目标: 昼夜作息+睡眠活动(体力恢复/缺觉软惩罚);入睡触发当天记忆批量固化,慢思考产出 dream 条目;记忆面板按类型(事件/洞察/梦境/对话)查看
- 验收标准: 角色入睡后体力恢复;次日记忆面板出现当天 dream 条目且内容与当天经历对应
- 状态: 未开始

### M6: NPC 体系

- 目标: 三层 NPC(核心 5~8 轻量 LLM / 背景 10~20 规则驱动);被交互唤醒留记忆;NPC 对话(轻量 LLM);后台 NPC 人设卡 CRUD
- 验收标准: requirement §11 NPC 人设对话/背景NPC 唤醒记忆/后台增删改查三条通过
- 状态: 未开始

### M7: 离线生活与飞书推送

- 目标: 常驻后端离线降频模拟(日计划 1 次/游戏日+规则引擎兜底);飞书 webhook(加签+队列);关键事件推送;重进生活摘要
- 验收标准: requirement §11「离线 8 小时重进收到推送+摘要」条通过
- 状态: 未开始

### M8: 后台完善+参观模式+打磨

- 目标: React Admin 全量(模型配置加密存储/成本面板+告警/世界控制);参观模式只读流;性能打磨;逐条过 requirement §11 全量验收
- 验收标准: requirement §11 全部通过
- 状态: 未开始

### 二期后置池

- 多人参与游玩、移动端、更多数值(饥饿/社交)、抱负系统深化——见 requirement §8 二期
