# agent-sims 数值规划(Numerical Design)

> 本文档是游戏数值的**唯一权威来源**(single source of truth)。
> 代码中的常量(`@sims/shared` 内容定义、`apps/server/src/config/balance.ts`)与本文表格一一对应;
> **调整数值须先改本文档再改代码**,并在表格后追加一行变更记录。
> 定稿: M3.6g(2026-10-04),首次系统性规划。

## 1. 设计总则

- **一日预算平衡**: 以"游戏日=1440 分钟"为单位演算,正常作息(睡眠 8h+工作 8h+三餐杂余)体力净增为正(留余量给健身/学习等高耗活动),不睡觉则 1 个工作日内跌入低体力区——用数值压力逼出"回家睡觉/吃饭"的真实行为,而不靠硬性规则。
- **净速率模型**: 活动数值即**净速率**(已含该活动期间的代谢),活动中不再叠加基础代谢;只有**待机**(无活动)走基础代谢衰减。数值语义清晰,Agent(M4)可直接读表规划。
- **真实感优先于好玩**: 消耗/补给梯度参照直觉(睡眠>就餐>静坐补给;健身最耗;久待机缓慢流失),绝对数值服务于节奏(1x 下一天≈24 分钟真实时间,16x≈90 秒)。

### 2.2 一日预算演算(验证平衡)

典型作息(睡眠 8h+打工 8h+就餐 1h+散步 1h+待机 6h):

```
+168(睡) -72(工) +3(餐) -2.4(散) -7.2(待) = +89 / 天
```

净 +89 的富余即"健康生活"的奖励空间——健身 1h(-24)+学习 1h(-7.2)后仍为正。打工按统一 -0.15 口径演算(§5.1,档位取消后全岗位一致)。
反例(不睡觉,全天打工+待机): -144-9.6 ≈ **-154/天** → 从 100 计约 **0.65 个工作日**即跌至低体力线。

### 2.3 阈值与生死

| 阈值 | 值 | 效果 |
|---|---|---|
| 低体力线 | energy ≤ **20** | 仅可基础活动(rest/stroll/meal),高强度拒绝 |
| 危急线 | energy ≤ **5** | 体力条红色(UI) |
| 死亡 | energy ≤ **0** | 幽灵态:拒绝一切意图,等待复活 |
| 复活 | 100 / 80 | /debug/revive 或 /lab 复活按钮 |

代码: `balance.ts` LOW_ENERGY_THRESHOLD / REVIVE_ENERGY / REVIVE_HAPPINESS。

### 3.2 容量机制

| 容器 | 体积上限 | 说明 |
|---|---|---|
| **背包**(随身) | **8** | 买入即入背包;任意地点可吃;≈4~8 份食物 |
| **冰箱**(家中) | **30** | 须在家(自有或租约有效)存/取;≈一周口粮 |

## 5. 经济(沿用 M3.2/M3.3 定稿,此处汇总)

### 5.1 职业与知识(2026-10-06 修订:类别平行模型,原四档双梯度取消)

- **知识(knowledge)**: 角色属性,0 起步;**完成一次完整学习(study 60 分)+1**;v1 不衰减、无上限;随快照下发。代码: server 活动完成回调累计,shared 定义常量。
- **岗位类别平行,无高低阶**(2026-10-06 用户定稿): 知识是**分支钥匙**——达到类别门槛后该类全部岗位任做;**类内同酬**,类间按劳动价值小幅差异(兜底 0.8/服务 1.0/建造 1.2),体力统一 -0.15(原「越高阶越省力」取消)。设计动机与机制见 02-goal-design.md §4.2。

## 6. 社交(social-design 定稿,M3.6l)

### 6.1 二轴有向关系(A→B 与 B→A 独立两条)

| 轴 | 范围 | 变化来源 |
|---|---|---|
| familiarity 熟悉度 | 0~100 | chat +6×递减(仅主动方);每日 -1(00:00 日翻转) |
| affinity 好感度 | −100~+100 | chat ±4×相性×递减(双向);可为负 |

### 6.2 chat 闲聊收益

| 参数 | 值 | 说明 |
|---|---|---|
| CHAT_FAMILIARITY_GAIN | 6 | ×当日递减,只涨主动方 |
| CHAT_AFFINITY_BASE | 4 | ×相性系数×当日递减,双向 |
| CHAT_HAPPINESS | 2 | ×当日递减,双方 |
| CHAT_DAILY_GAINED | **6** | 每游戏日**有收益**的次数;超出不拒绝、收益为 0(社交不设硬上限,Agent 间高频交流) |
| CHAT_DECAY_STEPS | 1 / 0.6 / 0.4 / 0.3 / 0.2 / 0.1 | 第 n 次 ×STEPS[n-1];超出档位 ×0;Σ=2.6 |

- 前提: 双方存活、非同一人、同处一地(曼哈顿 ≤ SOCIAL_PRESENCE_DISTANCE=2)。
- 相性系数 compatibility = 1.4 − 1.8×五维平均绝对差(特质 0~1: 雄心/享乐/宅/社交/节俭);
  完全同型 ×1.4,完全相反 ×−0.4(反感跌)。
- **不设硬上限**: 第 7 次起照常对话(气泡/日志照发,content 照常),但熟悉/好感/幸福增益全为 0
  ——防刷靠收益归零而非拒绝,适配 M4 Agent 高频社交。
- 节奏(6 次聊满): 熟悉度日净 +6×2.6−1 ≈ **+14.6/天** → 当天点头之交,朋友约第 2~3 天,
  挚友(相性 1.4)约第 4~5 天(好感线 65 为主门槛)。

### 6.3 同场增益

- 活动中角色按「附近(曼哈顿 ≤2)同在活动的其他角色数」获得幸福 +0.05/分/人,计人数封顶 3。
- 结算在活动净速率之后;空闲角色与距离外角色不计。

### 6.4 称号阈值(relationTitle 纯派生,不存储)

| 称号 | 条件 |
|---|---|
| 嫌弃 | affinity ≤ −30(优先判定) |
| 陌生人 | familiarity < **10** |
| 点头之交 | familiarity < **30** |
| 挚友 | affinity ≥ 65 且 familiarity ≥ 30 |
| 朋友 | 其余(熟悉度 ≥ 30) |

- 首次结成 朋友/挚友 发一次 friendship.formed 事件(嫌弃不庆祝)。

### 6.5 对话内容(模板池 v1)

- 按主动方 familiarity 分档: <30 寒暄 / 30~69 闲话 / ≥70 知心,同档随机一句(寒暄线随称号阈值 30 同步)。
- M4 LLM 接入后替换来源,协议不变(social.chat.content)。

代码: `@sims/shared social.ts`(阈值/公式)+ `apps/server config/balance.ts §社交`(收益参数)。

## 7. 维护约定
