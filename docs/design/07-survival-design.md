# 末日生存玩法设计(远期,概要级)

> 创建日期: 2026-10-05 · 对应需求基准 v1.5 §2.10
> 时间定位(用户定稿): 远期立项——本文档为概要设计,细化排在成长线核心(M4~M6)验收之后;本期仅落地素材库 survival 域预留与游戏类型占位。

## 1. 模式定位

- 与成长模式并列的游戏类型,创建世界时选择(引导向导第①步);两模式**共用**世界模拟底座(tick/寻路/意图/事件/快照同步)、Agent 内核与素材库
- 差异集中在: 世界生成规则、经济与数值体系、新增实体(资源点/僵尸/可放置物)、活动目录
- 单世界单模式,不中途切换(模式是世界创建参数的一部分)

## 2. 核心循环(类沙盒生存)

```
采集(伐木/采矿/搜刮) → 合成(配方: 材料→物资) → 制造(工具/武器/防御设施)
        │                                            │
        └──────── 建设与升级庇护所 ←──────────────────┘
                        │
僵尸波次(夜间/递增强度) → 守卫与维修 → 波次结算(生存奖励) → 下一循环
```

- **采集**: 地图生成时撒布资源点(树木→木材/岩石→石料/废墟→金属),agent 经 gather 意图耗时采集,资源入共享仓储
- **合成**: 配方表(recipe: 输入材料×数量 → 输出物资),后台可管理;craft 意图在合成台执行
- **制造**: 物资 → 放置物(木墙/尖刺/瞭望塔)或装备(武器/工具);放置沿用家具摆放机制(占地/阻挡/锚点)
- **庇护所**: 建筑基座(worldgen 生存规则生成) + agent 用墙体/设施扩展;庇护所完整度影响防御力

## 3. 僵尸威胁

- **波次节奏**: 白天准备(采集/建造),夜间僵尸从地图边缘入侵;波次编号递增,僵尸数量/速度/血量按波次曲线增长,精英怪偶发
- **僵尸 AI**: 规则驱动(寻路向庇护所/最近 agent),零 LLM——成本分级原则(需求根本原则 2)在生存模式同样硬约束
- **战斗**: agent 持武器自动迎击(意图驱动),血量归零角色进入"重伤休整"而非死亡(成长模式软惩罚原则延续)
- **合作分工**: 多 agent 经目标协商分工(采集组/建造组/守卫组)——复用 Agent 内核 Planning,方针层给定"生存优先"类目标

## 4. 数值与经济(生存模式独立规则)

| 项 | 成长模式 | 生存模式 |
|----|----------|----------|
| 核心数值 | 体力/幸福/金币 | 体力/健康/警备度 + 共享资源池(木材/石料/金属/食物) |
| 金币 | 主循环货币 | 弱化或移除(以物易物后置) |
| 软惩罚 | 降幸福/效率 | 建筑破损/资源损失;**角色不死**(重伤休整) |

## 5. 与既有体系的复用关系

> **引擎地基先行(2026-10-05 用户定稿)**: 采集/制作/修补三环在成长模式先落玩法先例(详见 09-production-design.md,M-G.6)——本节 gather/craft 意图、配方表、资源点均以其先例骨架落地: gather=work_task 资源节点变体,craft 复用同一配方注册表,维修复用同一可损耗实体注册表。

| 体系 | 复用方式 |
|------|----------|
| 世界模拟 | tick/事件总线/寻路/快照同步原样;新增实体类型进 world 层 |
| 意图指令层 | 新增 gather/craft/place/attack 意图;沿用 runIntent 单一入口与校验 |
| Agent 内核 | 人设/Memory/Planning 原样;方针目录扩展生存类目标 |
| 素材库 | survival domain(僵尸/武器/建材/庇护所组件)批量导入;tier 承载设施升级 |
| worldgen | 生存专属规则: 安全区/资源点撒布/刷怪边缘(§6) |
| 后台管理 | 配方表管理/波次曲线参数/僵尸种类开关 |
| 救治与死亡结算 | **医生救治单+死亡窗口挂起**(成长模式 M-G.5,02-goal §7)先落机制先例——work_task 目标可为角色、幽灵态挂起/超时结算/救治免扣;生存模式「重伤互救」沿用该骨架(注记 2026-10-06) |

## 6. 生存模式世界生成规则(M-S/S1.5 定稿,2026-10-07)

> 用户走查定稿四点: 墓地/废墟在镇外;森林/石头在镇外采集;小镇要有出口;镇外布局丰富化(旧医院/警察局/汽车)。真围栏+道路豁口出口;地图尺寸不变、镇内核心缩至 62%;growth 分支完全零变化。

**镇内核心(townCore)**: 以地图中心为中心的 62% 矩形(`TileMapDefinition.townCore` 可选字段,仅 survival 写入,web 忽略未知字段);镇内活动容量与 medium/large 已验证水位一致。

**场所配额分区(SURVIVAL_QUOTA)**: 配额行加 `area: 'town' | 'wild'`(缺省 town)——

| 分区 | 场所 | 配额 |
|---|---|---|
| 镇内 | home(sw)×2~3、camping(sw)、clinic(ne)、shop(ne) + 可选 restaurant/park | essential |
| 镇外 | graveyard(nw)、ruins(ne)、hospital(sw)、police(se) | 各 essential [1,1] |

- 撒放约束: town 场所矩形须含于核心(墙内缩缓冲);wild 场所须与核心外扩一圈不相交;三级策略(象限 20 次→全图 60 次→确定性扫描)全带约束;small 档 graveyard/ruins 收敛 [1,1](防小图野带放不下)
- 镇外新场所: **hospital 旧医院**(内景 12x9,bed×3/desk/bookshelf + hotel-and-hospital 主题小件,镇外落脚点)、**police 警察局**(内景 10x8,desk/counter/bench + police-station 主题小件);内景走既有墙+门+地板渲染,web 零改动

**镇界围栏(townFences)**: 沿核心四周边线逐格成段(连续格合并为整条矩形),**落在路格上的围栏位自动跳过**——门前主干道横穿边线处即天然镇出口(先路后栏: 围栏建于门前路 pass③ 之后);角格归横边,竖边让出两角。

**镇外簇(wildClusters)**: 森林 2~3 簇(10~13×6~8,small 8~10×5~6)+ 岩石区 1~2 簇(9~11×5~7,small 7~9×4~5),整簇须落镇外环带、避道路/场所±1 缓冲/簇间隔一圈;簇本身不阻塞行走,仅承载资源撒点与 decor 密植(森林密树/岩石区石块)。

**资源落点(survival)**: 树→镇外森林簇 6~10 棵;岩石→镇外岩石区 4~7 处;金属堆→废墟 3~6 处(废墟本在镇外);浆果→镇内公园/营地 4~8 丛(食物近家);垃圾堆→全图场所外不变。

**废土装饰(wreck 装饰池)**: 废车/电线杆/路障/人行道障碍(DECOR_POOLS 新键,立式限宽放宽 ≤4);`DecorDefinition.solid` 装饰占地转 blockedRects(废车/电线杆不可穿越);镇外沿出口路两侧+野带随机撒,密度档缩放。

**校验兜底**: 门洞/家具锚点/室内连通既有校验照跑;围栏豁口后 BFS 全入口连通校验,失败换种子重试(50 种子零兜底断言)。

## 7. 分阶段落地路径(占位,排期随成长线验收后定)

1. **S1 实体与采集**: 资源点/资源池/gather 意图/生存数值;无僵尸的"和平生存"可玩
   - **已交付(2026-10-07,M-S/S1 五提交)**: ①健康数值——health 0~100,饥饿线(体力<20)每分 -0.03、康复线(≥60)+0.02,五参数入 BALANCE 热调(04 §5.5);②重伤休整——health≤0 或 energy≤0 入幽灵态,救治窗口内医生救治满血复活/超时苏醒 30/30 幸福保留繁荣分不扣(软惩罚);③资源三件套——树木→木材/岩石→石料/废墟金属堆→金属,复用 M-G.6 采集引擎(NODE_MAX_CHARGES 5/4/3 次日重生),worldgen 撒点树 5~9 落公园营地/岩 3~6 落公园营地废墟/金属 3~6 落废墟;④金币经济 S1 保留(商店/租金/工资照旧,S3/S4 再议);⑤web——健康条(survival 显示)/重伤休整文案/三节点贴图+色块兜底/采集工单 UI 自动涌现;⑥测试——survival 数值断言组+worldgen 三件套落点档+growth 零回归(347 测试)
